ReTec Vision es un sistema que se busca diseñar para una mejor gestión de inventario de equipos de cómputo, sus componentes electrónicos y periféricos de diferentes negocios como maquiladoras, instituciones educativas o oficinas que manejen una cantidad considerable de computadoras para la posible reutilización de piezas aun con posible funcionalidad, así como una mejora en el desecho responsable de los distintos componentes electrónicos, equipos de cómputos y periféricos. El sistema registra fotografías como respaldo visual para tener un control de los componentes disponibles en los distintos equipos. Así como también categorizar el estado de los componentes que el equipo tenga en funcionamiento. Igualmente se busca que el cliente tenga un control total de inventario y piezas que tengan tanto como en funcionamiento en los equipos y también equipos o componentes que ya no estén en funcionamiento, pero aun tengan piezas en estado considerable para su uso lo que permite la implementación de componentes que aun cumplen con su funcionalidad en otros dispositivos que tengan una falla relacionada.  

Las tecnologías que están consideradas para el desarrollo de este sistema son ASP.NET Core MVC (.NET 10) usando Entity Framework Core, base de datos en SQL, y un diseño visual desarrollado con BootStrap 5
